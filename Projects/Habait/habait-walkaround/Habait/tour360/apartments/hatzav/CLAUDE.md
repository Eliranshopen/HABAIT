## Purpose
The Hatzav house (דגם חצב · 3 rooms · 80 m² · Harei Zahav, Moshav Na'ama) as a 360 tour on the RAINBOW tour system: RAINBOW's
interface and features, Hatzav's own panoramas, rings and catalog (never RAINBOW's furniture or catalog pictures; root §8.10).
Everything here except `prep.mjs`, `source.json` and this file is GENERATED by `prep.mjs` from the Hatzav job
(`C:\RnD\.wt\harei-zahav-naama\out\harei-zahav-naama\3-rooms`, called JOB) at $0.

## Gotchas
- The panorama frame: yaw 0 = image centre = plan +u, positive yaw toward plan +v (checked on the living and kitchen renders).
- `fidelity.mode` in apartment.json: `cg-render` for the Blender set (the model's own gate applies); `ai-over-cg` for the realism set — build-tour refuses it without `--ungated-ok`, RAINBOW's per-picture gate was not run (paid).
- The ruler's depth has walls, floor and ceiling only — no furniture.
