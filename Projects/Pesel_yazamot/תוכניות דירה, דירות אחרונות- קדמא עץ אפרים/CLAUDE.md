## Purpose
The developer's sales-plan sheets, one per apartment still for sale in Kedma, Etz Efraim: 11 PDF (buildings ד, ה) and 14 PNG (buildings א, ב, ג). Originals: read-only, never altered.

## Gotchas
- Every PDF is one page holding one raster image (7087×4961 px, Photoshop); there are no vectors and no text layer, so room names and dimensions are read from the picture.
- File names are Hebrew with spaces; the PNG names use `_` between building and apartment (`בניין ג_דירה 1.png`), the PDF names a space (`בניין ד דירה 1.pdf`).
