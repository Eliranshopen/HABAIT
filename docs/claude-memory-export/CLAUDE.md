## How to use it on another computer
Copy every `.md` file of this folder EXCEPT this `CLAUDE.md` into Claude Code's memory folder of the project on that computer: `%USERPROFILE%\.claude\projects\c--RnD\memory\` when the repo is at `C:\RnD` (the folder's name is made from the repo's path). Then start Claude Code in the repo: it loads `MEMORY.md` by itself.
