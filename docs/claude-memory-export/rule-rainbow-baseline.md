Every apartment visualization (360 tour or 3D walkaround) starts with ALL user-facing features of the RAINBOW tour in C:\RnD\Projects\Habait — e.g. the circle hotspots on furniture/accessories that swap them, the free-text design line.

**Scope (Eliran, same day):** the interface (buttons, look) and the features — NEVER RAINBOW's furniture, items or catalog pictures; swap alternatives come from the project's model or CC0 (Poly Haven).
