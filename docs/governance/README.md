## §4 House rules for editing a register
1. Append-only, dated rows; a wrong row is struck with a dated note, never deleted.
2. Every row carries its evidence path (a file, a screenshot, a probe result). A row without evidence is a question, not a fact.
3. A row is never permission to act — a prune, a deploy or a rotation is Eliran's explicit act, quoted in the run.
4. Ids (`OWED-001`, …) continue from the highest on disk; ⛔ never reuse one.
5. Secrets: names only, in every register, always.
